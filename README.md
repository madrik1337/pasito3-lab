# Pasito Lab

Нативная macOS-лаборатория для исследования Bluetooth Smoant Pasito 3: эмулятор получателя, BLE-сканер, GATT-клиент и журнал обмена. Интерфейс на SwiftUI, работа с Bluetooth через Core Bluetooth. Внешних библиотек нет.

## Возможности

- Один эмулятор с пресетами имени и значения контрольной характеристики.
- Сканирование BLE-устройств, фильтр кандидатов Pasito, RSSI и просмотр GATT.
- Подключение через сканер или локальный UUID, известный **этому Mac**.
- Чтение `0004`, подписка на уведомления `0003`, последовательность принятия `0100`.
- Редактор десяти целочисленных значений 0–255 с HEX-превью и разовой отправкой.
- Отдельный раздел постоянного повтора: запрос конфигурации или отправка своего конфига, интервал 1–60 секунд.
- Охват повтора: выбранное устройство или последовательный обход всех свежих кандидатов Pasito с проверкой GATT.
- Отдельное Debug-окно, поиск, фильтрация, просмотр исходного JSON и экспорт журнала.

## Сборка и запуск

Требуются macOS 14 или новее и актуальные Xcode Command Line Tools с поддержкой Swift Observation. Сборка выполняется для архитектуры текущего Mac.

```sh
xcode-select --install # если Command Line Tools ещё не установлены

git clone git@github.com:madrik1337/pasito3-lab.git
cd pasito3-lab
bash macos/build.sh
open 'macos/Pasito Lab.app'
```

Скрипт собирает приложение и подписывает его локальной ad-hoc подписью. Это не Developer ID-подпись и не notarized-дистрибутив. При первом запуске разрешите приложению доступ к Bluetooth.

### CLI-эмулятор

```sh
bash emulator/build.sh
./emulator/build/PasitoEmulator --name LE-S052 --duration 1200 --log /tmp/pasito-session.jsonl
```

Дополнительные параметры: `--advertise both|name|service`, `--control-hex HEX`. CLI воспроизводит сервер и пишет журнал; обратный клиент и автоматический приём доступны в GUI.

Не запускайте CLI и GUI-эмуляторы одновременно на одном адаптере: macOS может объединять их объявления.

## Быстрый старт

1. В разделе **Эмулятор** выберите пресет `LE-S052` и запустите его.
2. Включите Bluetooth/Share на своём Pasito.
3. В **Сканере** начните поиск, выберите устройство и нажмите **Подключить и принять**.
4. Выполните передачу через Share на Pasito. Приём подписывается на `0003`, записывает `0100` в `0004` и читает ответ.
5. Откройте **Журнал** или отдельное окно **Debug** (`Cmd+Shift+D`). Источник `client` — обмен с GATT настоящего устройства, `emulator` — запросы к GATT приложения.

Если устройство появляется только после выбора получателя в Share, инициируйте подключение клиента и затем выберите получателя. Ожидание подключения ограничено 30 секундами, операции — 12 секундами.

### Свой конфиг

В разделе **Эмулятор** задайте десять значений, выберите UUID через сканер и нажмите **Отправить конфиг один раз**. Один элемент кодируется одним байтом: за пределами 0–255 отправка запрещена, значения не обрезаются. Этот предел относится к кодированию, а не к допустимой мощности устройства.

Обратная запись `02 + десять значений` воспроизводит наблюдавшуюся форму входящего сообщения. Применение такого конфига устройством **экспериментальное**. Успешный ATT-ответ означает принятие записи стеком, а не подтверждённое применение настроек. Длительности ступеней пока не декодируются.

### Постоянный повтор

Выберите действие, интервал и охват в отдельном разделе. При старте фиксируются данные конфига. Во время занятой операции такты пропускаются, очередь не накапливается.

Охват **Все кандидаты Pasito** включает сканирование и по очереди обходит connectable-кандидаты с объявлениями не старше 30 секунд, а также текущее подключённое устройство. Новые кандидаты добавляются динамически. Команды отправляются только после обнаружения соответствующего GATT-сервиса и характеристик; несовпадающие кандидаты исключаются до следующего запуска цикла. Совпадение имени или UUID не является аутентификацией устройства — используйте режим в своей тестовой среде.

Ошибка/тайм-аут останавливают весь цикл. Кнопка остановки доступна и в боковой панели. Ручное отключение, остановка эмулятора, остановка сканера в общем режиме и выход также прекращают повтор. Уже переданную ATT-запись отозвать нельзя. После перезапуска приложения цикл автоматически не включается.

## Протокол и ограничения

Сервис: `6E400001-B5A3-F393-E0A9-E50E24DCCA9D` — окончание **9D**, не `9E` стандартного Nordic UART.

| Характеристика | Свойства | Назначение в приложении |
| --- | --- | --- |
| `6E400002-…-CCA9D` | Write without response | Приём и журналирование записей |
| `6E400003-…-CCA9D` | Notify | Подписка на уведомления устройства |
| `6E400004-…-CCA9D` | Read, Write | Контрольные сообщения и кадр конфигурации |

Сервер хранит записанное значение `0004` в памяти. Без заданного значения чтение возвращает Request Not Supported. Поддерживаются проверки смещения и длины записи. Сервер не выдумывает прикладные подтверждения.

Полный протокол не документирован. Нет подтверждённых функций OTA, чтения истории затяжек или скрытого управления. Публичный Core Bluetooth не позволяет этому приложению произвольно задавать manufacturer data, MAC или RSSI. Один адаптер не превращается в несколько независимых устройств при запуске нескольких процессов.

Список GATT и журнал отражают callback Core Bluetooth, а не сырые ATT/HCI-пакеты в эфире. Пустой серверный журнал не исключает наличия BLE-соединения: для наблюдавшегося сценария передачи нужен и обратный GATT-клиент.

## Локальные данные

Журналы создаются **при работе приложения** в:

```text
~/Library/Application Support/Pasito Lab/Logs/session-<UUID>.jsonl
```

Они содержат идентификаторы обнаруженных устройств и байты обмена. На экране — последние 2000 событий, в файле — весь сеанс. Пауза/очистка экрана не удаляют файл. Рекламные события ограничены одним событием в пять секунд на устройство. Черновик конфигурации, выбранный UUID и настройки интерфейса сохраняются локально через UserDefaults.

В этот репозиторий включены только исходники и сборочные скрипты. Реальные захваты, пользовательские UUID/MAC, журналы, скриншоты, тестовые наборы и результаты локальных экспериментов **не включены**. Они и сборочные артефакты исключены через `.gitignore`.

## Структура

```text
macos/Sources/       SwiftUI-интерфейс и Bluetooth-контроллер
macos/build.sh       Сборка .app
emulator/Core.swift Работа с байтами и HEX
emulator/main.swift CLI GATT-сервер
emulator/build.sh   Сборка CLI
```

Базовые типы сообщений и UUID оставлены в исходниках как часть реализации протокола; адреса конкретных устройств не зашиты. Начальный редактор содержит синтетический шаблон из десяти значений 20.
